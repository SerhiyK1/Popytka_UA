# Popytka UA - Документація архітектури

## Огляд
**Popytka UA** — це додаток для спільного використання поїздок (райдшеринг), розроблений для українського ринку. Він з'єднує водіїв із пасажирами для міжміських та локальних поїздок.

## Технологічний стек (Tech Stack)
- **Фреймворк**: Flutter (Dart)
- **Керування станом**: Riverpod (Code Generation + Hooks)
- **Навігація**: GoRouter
- **Бекенд (BaaS)**: Firebase
    - **Аутентифікація**: Firebase Auth (телефон, Google та ін.)
    - **База даних**: Cloud Firestore
    - **Сховище**: Firebase Storage (зображення)
- **Карти**: `flutter_map` з даними OpenStreetMap (тайли CartoCDN)
- **Геокодування**: Nominatim Service (OSM)
- **Локалізація**: `flutter_localizations` (en, uk, ru)

## Структура проекту
Проект наслідує архітектуру **Feature-First Clean Architecture**:

```
lib/
├── data/               # Шар даних: реалізації, репозиторії, джерела даних
│   ├── repositories/   # Реалізації репозиторіїв (взаємодія з Firestore)
│   ├── providers/      # Провайдери Riverpod
│   └── services/       # Зовнішні сервіси (Nominatim та ін.)
├── domain/             # Доменний шар: сутності, інтерфейси
│   └── models/         # Data Classes на Freezed (UserModel, RideModel та ін.)
├── presentation/       # Шар представлення: UI, віджети, стан
│   ├── screens/        # Повноекранні екрани, організовані за функціями
│   │   ├── auth/
│   │   ├── home/
│   │   ├── profile/
│   │   └── ...
│   ├── theme/          # Тема додатка, кольори, стилі тексту
│   ├── widgets/        # Багаторазові UI компоненти
│   └── router/         # Конфігурація GoRouter
└── l10n/               # Файли локалізації (.arb)
```

## Моделі даних (Domain)
Ключові сутності в системі:
- **UserModel**: Користувачі (водії/пасажири)
- **RideModel**: Поїздка, створена водієм
- **BookingModel**: Бронювання місця пасажиром
- **ChatModel / MessageModel**: Внутрішній чат
- **LocationModel**: Дані геолокації

## Ключові функції
1.  **Аутентифікація**: Безпечний процес входу/реєстрації.
2.  **Пошук поїздок**: Пошук за точкою відправлення, призначення та датою.
3.  **Створення поїздки**: Водії публікують поїздки з деталями (авто, ціна, місця).
4.  **Бронювання**: Пасажири бронюють місця в доступних поїздках.
5.  **Повідомлення**: Чат у реальному часі між пасажирами та водіями.
6.  **Профіль**: Керування профілем, перемикання ролей (водій/пасажир), Гаманець (Wallet).

# МЕТАДАНІ ДОДАТКА - Popytka UA

## Основна інформація
- **Назва додатка:** Popytka UA
- **Назва пакета (Package Name):** com.example.popytka_ua
- **Версія:** 1.0.0+1
- **Цільовий ринок:** Україна 🇺🇦
- **Категорія:** Транспорт та подорожі

## Описи

### Українська (Основна)
**Короткий опис (80 символів):**
Попутка UA - безпечні поїздки по Україні. Знайди попутника або пасажира!

**Повний опис:**
Попутка UA - це сучасний додаток для пошуку попутників та організації спільних поїздок по Україні. 

🚗 **Основні можливості:**
• Швидкий пошук поїздок за маршрутом
• Безпечна система бронювання місць
• Чат з водіями та пасажирами
• Рейтингова система користувачів
• Підтримка української та англійської мов

🛡️ **Безпека:**
• Верифікація через Google
• Рейтинги та відгуки користувачів
• Можливість поділитися деталями поїздки

💰 **Економія:**
• Ділення витрат на паливо
• Доступні ціни на поїздки
• Екологічно чистий транспорт

Приєднуйтесь до спільноти Попутка UA та подорожуйте безпечно і економно!

### Англійська (переклад)
**Короткий опис:**
Popytka UA - безпечне спільне використання поїздок по всій Україні. Знайдіть водіїв або пасажирів!

**Повний опис:**
Popytka UA - це сучасний додаток для спільного використання поїздок (ridesharing) для пошуку супутників та організації спільних поїздок по всій Україні.

🚗 **Ключові особливості:**
• Швидкий пошук поїздки на основі маршруту
• Безпечна система бронювання місць
• Чат з водіями та пасажирами
• Система рейтингу користувачів
• Підтримка української та англійської мов

🛡️ **Безпека:**
• Верифікація через Google
• Рейтинги та відгуки користувачів
• Можливість ділитися деталями поїздки

💰 **Економія:**
• Спільні витрати на пальне
• Доступні ціни на поїздки
• Екологічно чистий транспорт

## Необхідні скріншоти
1. **Головний екран (Home Screen)** - Інтерфейс пошуку
2. **Результати пошуку (Search Results)** - Доступні поїздки
3. **Деталі поїздки (Ride Details)** - Інтерфейс бронювання
4. **Екран профілю (Profile Screen)** - Профіль користувача
5. **Повідомлення (Messages)** - Інтерфейс чату
6. **Мої поїздки (My Rides)** - Поїздки користувача
